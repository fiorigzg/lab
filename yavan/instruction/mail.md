В качестве языка для обработки предлагаю тебе взять яванский. Вот ссылка на инструкцию по работе с языками:
https://yarolika00.notion.site/5305a12e06c84d1eb3a47d341113d8b0


От себя добавлю следующие моменты:

1. Перед поиском текстов в указанных в инструкции источниках стоит сначала посмотреть, нет ли уже готовых корпусов. Это же касается и инструментов по работе с языком, например, если получилось найти готовый лемматизатор, то можно попробовать его перед тем, как писать собственный

2. Нужно обязательно сохранять источники, откуда брались тексты. Если они собирались в открытых источниках, то следует сохранить название произведения и автора, если использовался готовый корпус, нужно привести на него ссылку

3. Важно, чтобы обработанные корпуса не содержали переводной литературы (например, в корпусе японского не должно быть «Гарри Поттера», поскольку у него языком оригинала является английский), при этом в сырой корпус её включить можно, но тогда нужно указать, что далее они не использовались

4. Эмбеддинги типа SVD считаются по **текстовому** корпусу (1 строка = 1 текст), эмбеддинги CBoW — по **сегментному** корпусу (1 строка = 1 предложение). Обращу внимание, что сегментный корпус можно сделать из текстового, поделив тексты на предложения


По завершении работы ожидаются следующие материалы:

1. Необработанный корпус с текстами / предложениями до очистки и лемматизации (по возможности, чтобы каждый текст корпуса для SVD лежал в отдельном txt файле с исходным названием)

2. Полный пайплайн обработки — алгоритм очистки текстов и лемматизатор

3. Обработанные текстовый (для SVD) и сегментный (для CBoW) корпуса с очищенными и лемматизированными текстами / предложениями (также по возможности, чтобы каждый текст корпуса для SVD лежал в отдельном txt файле с исходным названием)

4. Эмбеддинги SVD (размерность не больше 32) и CBoW

5. Файлик readme с описанием того, в какой папке/каком файле что лежит
