# Скрипты сбора и первичной чистки сырого корпуса

Все скрипты запускаются из папки `work/` (или из `work/scripts/` — пути
внутри относительные). Дата сбора корпуса: 2026-06-10.

## Скачивание (сырой корпус)

| Скрипт | Для чего |
|---|---|
| `download_sastra_org.py` | Главный источник. Качает ~3000 текстов sastra.org (Yayasan Sastra Lestari) из снапшотов **Wayback Machine** (живой сайт блокирует нашу сеть). Список страниц — из Wayback CDX API, дедупликация по ID статьи, 12 потоков, резюмирование (пропуск уже скачанных файлов). Поддерживает 4 версии вёрстки сайта (2013–2016 ja_purity, 2017–2021 UIkit, 2022+ и 2025+ Cassiopeia). Выход: `corpus_raw/sastra-org/<категория>/<slug>.txt`, метаданные `_metadata.tsv`, отказы `_failed.txt`. |
| `download_sastra_live.py` | Второй канал для sastra.org: качает **живой сайт** через прокси r.jina.ai (отдаёт markdown, конвертируется в текст). Идёт по тому же списку URL, но с конца — навстречу Wayback-каналу. 404-е оставляет Wayback-каналу. Выход в те же папки, метаданные `_metadata_live.tsv`. |
| `download_alangalangkumitir.py` | Качает все 672 поста блога alangalangkumitir.wordpress.com (транскрипции серата/сулуков/бабадов) через публичный REST API wordpress.com. Выход: `corpus_raw/alangalangkumitir/<название>__<id>.txt` + `_metadata.tsv`. |
| `download_kidemang.py` | Качает литературные разделы ki-demang.com: 30 рассказов-cerkak, романы-сериалы «Rajapati» (18 гл.) и «Ting» (20 гл.), Babad Tanah Jawi (26 гл.), Bharatayuddha (11 гл.); при проверке полноты добраны разделы naskah kina (Negarakertagama, Pararaton, Ramayana, suluk и др.). Выход: `corpus_raw/ki-demang/<раздел>__<slug>.txt` + `_metadata.tsv`. |
| `check_sastra_completeness.py` | Проверка полноты sastra.org: обход листингов категорий живого сайта через прокси, сравнение с уже скачанным, добор недостающего. Листинги живого сайта рендерятся JS, поэтому через прокси видны частично — основной добор делает следующий скрипт. |
| `probe_sastra_ids.py` | Добор sastra.org перебором ID статей: Joomla отдаёт статью по `index.php?...&id=N`; перебираются все ID-дыры между скачанными. Добранное — в `corpus_raw/sastra-org/_recovered/` (категория по названию определяется на очистке). |
| `download_panjebarsemangat.py` | Журнал Panjebar Semangat (еженедельник на яванском, Сурабая): ~2600 статей 2010–2019 из снапшотов Wayback (живой домен с ~2020 г. захвачен спам-сайтом, поэтому берутся только снапшоты до 2020 г.). Два поколения вёрстки (WordPress и berita-*.html), рубрика статьи пишется в метаданные. Выход: `corpus_raw/panjebarsemangat/<slug>.txt` + `_metadata.tsv`. |

## Одноразовые чистки обвязки сайта (уже применены)

Эти скрипты правят только служебный мусор скачивания (меню сайта, навигацию,
подсказки поиска), **сам текст произведений не меняют**. Идемпотентны.

| Скрипт | Для чего |
|---|---|
| `sweep_sastra_furniture.py` | Убирает из начала файлов sastra.org служебные строки страницы («Judul», «Sambungan», «Citra», блок «Pencarian Teks», «Terakhir diubah», обрезок HTML-тега), сохранённые до фикса экстрактора. |
| `clean_jina_chrome.py` | Для 523 файлов, скачанных через r.jina.ai: убирает шапку (меню «* Beranda…», яванский календарь, оглавление «…Kategori: …») и подвал (от «Informasi umum» до «sastra.org ©»). |

## Очистка корпуса

| Скрипт | Для чего |
|---|---|
| `clean_corpus.py` | Полная очистка `corpus_raw` → `corpus_clean` (БЕЗ лемматизации). Этапы: исключение словарей/грамматик и нотаций гамелана; удаление артефактов оцифровки (маркеры страниц, сноски, редакторские пометки); построчный фильтр языка (яванский остаётся; индонезийский, голландский, английский — вон); нормализация (lowercase, сворачивание диакритики ê→e и т.п., старая орфография oe→u, tj→c, dj→j); цифры → ORDINAL1, личные местоимения → PRON1; сегментация на предложения (по .?!; и стиховым разделителям \| и \|\|). Корпус разделён на «вёдра» (источники не смешиваем): `sastra` (литература — основной), `arsip`, `jurnal` (довоенные журналы), `majalah` (Panjebar Semangat 2010-х); статьи из `sastra-org/_recovered/` раскладываются по вёдрам по названию. Полное описание решений — в докстринге скрипта. |

Выход очистки (`corpus_clean/`):
- `texts/<ведро>/<имя>.txt` — очищенный текст, 1 предложение = 1 строка;
- `corpus_text_<ведро>.txt` — 1 строка = 1 текст (текстовый корпус, для SVD);
- `corpus_segments_<ведро>.txt` — 1 строка = 1 предложение (сегментный, для CBoW);
- `_excluded.tsv` — исключённые файлы с причинами; `_stats.txt` — статистика.

## Лемматизация

Готового лемматизатора яванского не существует (проверено на шаге 0) —
написан свой, на правилах, по образцу алгоритма Nazief–Adriani для
индонезийского: «снять аффикс → проверить, что получился корень из
лексикона». Подробное описание правил — в докстринге `jav_lemmatizer.py`.

| Скрипт | Для чего |
|---|---|
| `build_lexicon.py` | Собирает лексикон корней `lexicon/roots.txt` (~22 тыс.) из словарей, лежащих в сыром корпусе: заголовочные слова Javanese-English Dictionary (Horne 1974, 31 файл) и Javaansch-Nederduitsch Woordenboek (Gericke & Roorda 1847, 20 частей) + синонимические ряды dasanama (кави-лексика для стихов). Плюс кэш частот корпуса `lexicon/freq.tsv` (тай-брейк кандидатов). |
| `jav_lemmatizer.py` | Сам лемматизатор (модуль). Правила: редупликации (полная, с чередованием, dwipurwa), суффиксы ngoko/krama (-e/-ipun, -ake/-aken, -an, …), префиксы (di-/dipun-, ka-, tak-, sa-, pa-, …), назальный N- с восстановлением первой согласной (nulis→tulis, mangan→pangan, ngarang→karang), стиховые -(n)ing/-(n)ira, инфиксы -um-/-in-. Поиск в ширину ≤3 снятий; не нашли корень — слово не трогаем. Режим оценки: `--eval eval/jv_csui-ud-test.conllu`. |
| `lemmatize_corpus.py` | Применяет лемматизатор к `corpus_clean/` → `corpus_lemma/` (та же структура: texts/, текстовый и сегментный корпуса по вёдрам, `_stats.txt` со сжатием словаря). |

Оценка на трибанке UD Javanese-CSUI (1000 предложений, золотые леммы,
https://github.com/UniversalDependencies/UD_Javanese-CSUI): точность 87%
по всем токенам; из сделанных лемматизатором замен с золотом совпадает 74%.
Значительная часть расхождений — конвенции UD (там леммируют даже
лексикализованные слова: gamelan→gamel, marang→arang; мы такие сознательно
оставляем — для эмбеддингов это самостоятельные единицы).
Известные ограничения: стяжения гласных на стыке морфем (turu+an→turon)
не разворачиваются; krama-лексика не переводится в ngoko (это уже не
морфология); изредка страдают имена собственные (lamongan→lamong).
