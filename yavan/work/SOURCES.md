Очищенный корпус (фильтр языка, нормализация, без лемматизации) —

Правила проекта: Википедию и подобное не используем; основа — литература
(сказки, классика, произведения местных авторов), в крайнем случае местные
статьи. Переводная литература в обработанный корпус не входит (если попала в
сырой — помечена здесь и исключается на этапе обработки).

## 1. sastra.org — Yayasan Sastra Lestari («Сохранение яванской литературы»)

- **Что это**: крупнейшая библиотека оцифрованной яванской литературы
  (транскрипции в латинице с диакритикой): классические произведения
  (serat, babad, suluk), романы нач. XX века, довоенные журналы.
- **URL**: https://www.sastra.org/
- **Как качали**: прямой доступ из нашей сети недоступен (connection refused
  на уровне TCP; сайт при этом жив — блокирует сети). Два канала:
  1) снапшоты Wayback Machine (`web.archive.org/web/<ts>id_/<url>`); список
  страниц — через Wayback CDX API, дедупликация по ID статьи;
  2) живой сайт через прокси r.jina.ai (markdown → текст), навстречу
  первому каналу. Итог: 3036 из 3038 уникальных страниц; 2 оставшиеся
  текста не содержат (стр. «pangkalan data» — индекс БД, и одна страница
  только со сканом, на живом сайте 403).
  Проверка полноты (2026-06-11): листинги живого сайта рендерятся JS и
  через прокси видны не полностью, поэтому добор — перебором дыр в
  нумерации ID статей (Joomla отдаёт статью по `index.php?...&id=N`,
  `scripts/probe_sastra_ids.py`): из 433 ID-кандидатов 277 пустых/404,
  83 без текста, 73 страницы добрано, из них 65 — настоящие тексты
  (~634 тыс. слов; свежие добавления сайта, которых нет в Wayback:
  Menak 5, Babad Purubaya по рукописи Британской библиотеки 1813 г.,
  Wulang Rèh 1858, Nitisruti и др.) → `sastra-org/_recovered/`;
  1 ID закрыт самим сайтом (403). Категорию статьи этот канал не
  сообщает — раскладка по вёдрам по названию на этапе очистки.
- **Лицензия сайта**: Creative Commons Attribution-NonCommercial 4.0
  (из meta rights живых страниц).
- **Скрипты**: `scripts/download_sastra_org.py` (Wayback),
  `scripts/download_sastra_live.py` (живой сайт через прокси);
  одноразовые чистки обвязки: `scripts/sweep_sastra_furniture.py`,
  `scripts/clean_jina_chrome.py`.
- **Куда**: `corpus_raw/sastra-org/<категория>/<slug>.txt`;
  метаданные (название, автор, год, URL, снапшот) — `corpus_raw/sastra-org/_metadata.tsv`.
  Название файла = slug страницы, содержит название произведения, автора, год.
- **Категории** (в порядке приоритета):
  - `kisah-cerita-dan-kronikal` — повести, новеллы, бабады (хроники), донгенги
    (сказки), Serat Centhini (транслитерация Kamajaya 1985-91), Menak,
    яванская Махабхарата и др. ~1100 страниц.
  - `agama-dan-kepercayaan` — сулуки, религиозно-мистическая поэзия (~300).
  - `bahasa-dan-budaya` — piwulang (дидактическая литература), культура (~900).
  - `arsip-dan-sejarah` — исторические архивы, письма (~1100).
  - `koran-majalah-dan-jurnal` — довоенные яванские журналы, в т.ч. Kajawèn
    (1920–30-е) — это «местные статьи», запасной материал (~800).
- **Примеры произведений**: «Rangsang Tuban» (Padmasusastra, 1912),
  «Cênthini» (Kamajaya, 1985-91), Babad Tanah Jawi, Babad Giyanti.
- **Примечание**: яванская Махабхарата/Bharatayuddha и Menak — традиционные
  яванские *переложения* (не прямые переводы), стандартно считаются яванской
  литературой; решение об их включении можно уточнить у куратора.
  Явных переводов современной иностранной литературы в выборке нет.
- **ВНИМАНИЕ для этапа обработки** (в сыром корпусе оставлено как есть):
  - в `bahasa-dan-budaya` есть двуязычные словари (Javanese-English
    Dictionary Horne 1974, Dictionnaire javanais-français 1870,
    яв.-нидерландские) и грамматики — НЕ естественный текст, исключить;
  - в `arsip-dan-sejarah` и `bahasa-dan-budaya` ~375 коротких файлов —
    нотации гамелана (гендинги), а не текст — отсев по длине;
  - часть произведений существует в 2+ изданиях/транслитерациях
    (напр. Centhini: Soeradipoera 1912 и Kamajaya 1985-91) — это разные
    тексты, не дубли; точные дубли страниц проверить на обработке;
  - метаданные: `_metadata.tsv` (Wayback-канал) и `_metadata_live.tsv`
    (живой канал), формат одинаковый.

## 2. alangalangkumitir.wordpress.com — «AlangAlangKumitir»

- **Что это**: блог-библиотека транскрипций классических яванских текстов:
  serat, suluk, babad, kidung (Serat Wedhatama, Serat Wirid Hidayat Jati,
  Babad Dipanegara, Babad Tanah Jawi и десятки других).
- **URL**: https://alangalangkumitir.wordpress.com/
- **Как качали**: публичный REST API wordpress.com
  (`public-api.wordpress.com/rest/v1.1/sites/alangalangkumitir.wordpress.com/posts/`),
  все 672 поста.
- **Скрипт**: `scripts/download_alangalangkumitir.py`
- **Куда**: `corpus_raw/alangalangkumitir/<title>__<post_id>.txt`;
  метаданные — `corpus_raw/alangalangkumitir/_metadata.tsv`.
- **ВНИМАНИЕ**: часть постов — комментарии/переводы на индонезийском
  (напр. «...TERJEMAHAN», «AJARAN ... DALAM ...») или двуязычные
  (яванская строфа + индонезийский перевод). В сыром корпусе сохранены все;
  на этапе очистки оставляем только яванские тексты/фрагменты
  (фильтр по языку).

## 3. ki-demang.com — Ki Demang Sokowaten

- **Что это**: яванский культурный портал (Джокьякарта): современные рассказы
  и романы с продолжением на яванском, прозаические пересказы классики.
- **URL**: https://ki-demang.com/
- **Как качали**: прямой скрейпинг разделов (Joomla).
- **Скрипт**: `scripts/download_kidemang.py`
- **Куда**: `corpus_raw/ki-demang/<раздел>__<slug>.txt`;
  метаданные — `corpus_raw/ki-demang/_metadata.tsv`.
- **Разделы**:
  - `cerita-cekak-jawa` — 30 современных рассказов (cerkak);
  - `cerita-sambung-rajapati` — роман-сериал «Rajapati» (18 глав);
  - `cerita-sambung-ting` — роман-сериал «Ting» (20 глав);
  - `babad-tanah-jawi` — прозаический пересказ Babad Tanah Jawi (26 глав);
  - `bharatayuddha` — пересказ Бхаратаюдды (11 глав; яванское переложение,
    см. примечание к sastra.org).
- **Примечание**: сайт использует фонетическую орфографию с диакритикой
  (å, ê, í, ó, ú) — нормализуется при очистке.

## 4. panjebarsemangat.co.id — журнал Panjebar Semangat (через Wayback)

- **Что это**: яванский еженедельник (Сурабая, выходит с 1933 г.):
  рассказы (cerkak), романы с продолжением (cerita sambung),
  страшилки (Alaming Lelembut), статьи и новости на яванском.
  По правилам проекта это смешанный материал «литература + местные статьи» —
  идёт в ОТДЕЛЬНОЕ ведро `majalah` (с основным корпусом не смешивается);
  рубрика каждой статьи сохранена в метаданных, при необходимости
  художественную часть можно отделить от новостной.
- **URL**: https://www.panjebarsemangat.co.id/ — ВНИМАНИЕ: живой домен
  с ~2020 г. захвачен спам-сайтом (индонезийские обзоры игр/казино),
  поэтому качаем ТОЛЬКО снапшоты Wayback до 2020 г.
- **Как качали**: Wayback CDX API → ~2600 уникальных статей 2010–2019;
  два поколения вёрстки (WordPress 2010–2014 в корне домена и движок
  berita-NNNN-*.html 2016–2019), оба поддержаны экстрактором.
- **Скрипт**: `scripts/download_panjebarsemangat.py`
- **Куда**: `corpus_raw/panjebarsemangat/<slug>.txt`; метаданные
  (slug, заголовок, рубрика, URL, снапшот) — `_metadata.tsv`.

## 6. Готовые корпуса/инструменты (проверка по п.1 инструкции)

- Готовые корпуса яванского: CC-100/OSCAR/Leipzig (веб-краулы и Википедия) —
  не подходят (не литература, смешанные источники).
  Panjebar Semangat corpus — см. выше.
- fastText cc.jv.300 (готовые эмбеддинги, обучены на Common Crawl + Wikipedia):
  https://fasttext.cc/docs/en/crawl-vectors.html — можно использовать для
  сравнения на этапе эмбеддингов.
- Лемматизация/морфология яванского: готовой spacy-модели нет; есть
  ресурсы UD Javanese-CSUI (treebank), MorphInd для индонезийского не
  подходит. Вероятно, потребуется собственный лемматизатор
  (яванская морфология: аффиксы N-, di-, -ake, -an, -e и т.д.).
