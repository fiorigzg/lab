# Источники корпуса

Что нашли, откуда качали, что используем. Дата сбора 2026-06-10, добор
2026-06-11. Хронология работ и описание папок в `README.md`, скрипты
скачивания в `scripts/`.

Правила проекта: Википедию и вики-источники не используем, основа это
литература (сказки, классика, местные авторы), в крайнем случае местные
статьи. Переводная литература в обработанный корпус не входит.

## 1. sastra.org

Yayasan Sastra Lestari, крупнейшая библиотека оцифрованной яванской
литературы: serat, babad, suluk, романы начала XX века, довоенные журналы.
Транскрипции в латинице с диакритикой. https://www.sastra.org/
Лицензия CC BY-NC 4.0 по meta rights живых страниц.

Прямой доступ из нашей сети закрыт (connection refused, сайт блокирует сети),
поэтому качали в два канала навстречу друг другу: снапшоты Wayback Machine по
списку из CDX API и живой сайт через прокси r.jina.ai. Взяли 3036 из 3038
уникальных страниц, две оставшиеся текста не содержат.

Проверка полноты: листинги живого сайта рендерятся через JS и в прокси видны
не полностью, поэтому добирали перебором дыр в нумерации ID статей. Из 433
кандидатов добрано 73 страницы, из них 65 настоящих текстов на ~634 тыс. слов
(Menak 5, Babad Purubaya по рукописи Британской библиотеки 1813 г.,
Wulang Reh 1858, Nitisruti). Лежат в `sastra-org/_recovered/`, категорию этот
канал не сообщает, поэтому по вёдрам их раскладываем по названию.

Куда: `corpus_raw/sastra-org/<категория>/<slug>.txt`, имя файла содержит
название произведения, автора и год. Метаданные в `_metadata.tsv` (Wayback)
и `_metadata_live.tsv` (живой канал), формат одинаковый.

Категории: `kisah-cerita-dan-kronikal` повести, бабады, сказки, Centhini,
Menak, яванская Махабхарата (666 файлов); `bahasa-dan-budaya` piwulang и
культура (578); `koran-majalah-dan-jurnal` журналы 1920-30-х (685);
`arsip-dan-sejarah` архивы и письма (870); `agama-dan-kepercayaan` сулуки и
мистика (237).

Что важно для обработки:
- в `bahasa-dan-budaya` лежат двуязычные словари (Horne 1974, Gericke-Roorda
  1847, dasanama) и грамматики. Как текст они исключаются, но из них строится
  лексикон корней для лемматизатора;
- в `arsip-dan-sejarah` и `bahasa-dan-budaya` около 375 коротких файлов это
  нотации гамелана, отсеиваются по длине;
- часть произведений есть в двух и более транслитерациях (Centhini
  Soeradipoera 1912 и Kamajaya 1985-91). Это разные тексты, не дубли;
- яванская Махабхарата, Bharatayuddha и Menak это традиционные яванские
  переложения, не прямые переводы, стандартно считаются яванской
  литературой. Явных переводов иностранной литературы в выборке нет.

## 2. alangalangkumitir.wordpress.com

Блог-библиотека транскрипций классики: Serat Wedhatama, Serat Wirid Hidayat
Jati, Babad Dipanegara, Babad Tanah Jawi и десятки других.
https://alangalangkumitir.wordpress.com/

Качали через публичный REST API wordpress.com, все 672 поста, сверка с API
показала, что на месте все.

Куда: `corpus_raw/alangalangkumitir/<title>__<post_id>.txt`, метаданные в
`_metadata.tsv`.

Что важно: часть постов это комментарии и переводы на индонезийском или
двуязычные (яванская строфа плюс индонезийский перевод). В сыром корпусе
сохранены все, на очистке остаются только яванские фрагменты.

## 3. ki-demang.com

Яванский культурный портал из Джокьякарты: современные рассказы cerkak,
романы с продолжением, прозаические пересказы классики. Единственный источник
современного языка. https://ki-demang.com/

Качали прямым скрейпингом разделов. При проверке полноты нашли 6 пропущенных
разделов меню naskah kina (Negarakertagama, Pararaton, Ramayana,
suluk-padhalangan, sinopsis-pakeliran, puspawarna), добрали.

Куда: `corpus_raw/ki-demang/<раздел>__<slug>.txt`, метаданные в
`_metadata.tsv`.

Разделы: cerita-cekak-jawa (30 рассказов), cerita-sambung-rajapati (18 глав),
cerita-sambung-ting (20 глав), babad-tanah-jawi (26 глав), bharatayuddha
(11 глав).

Что важно: сайт использует фонетическую орфографию с диакритикой, она
нормализуется при очистке.

## 4. panjebarsemangat.co.id

Яванский еженедельник из Сурабаи, выходит с 1933 г.: рассказы cerkak, романы
с продолжением, страшилки Alaming Lelembut, статьи и новости. Это смешанный
материал, литература плюс местные статьи, поэтому идет в отдельное ведро
`majalah` и с основным корпусом не смешивается. Рубрика каждой статьи есть в
метаданных, при необходимости художественную часть можно отделить.

Живой домен примерно с 2020 г. захвачен спам-сайтом, поэтому берем только
снапшоты Wayback до 2020 г. Через CDX API взяли около 2600 статей 2010-2019.
Два поколения вёрстки, оба поддержаны экстрактором.

Куда: `corpus_raw/panjebarsemangat/<slug>.txt`, метаданные в `_metadata.tsv`.

## 5. Проверено и не используется

- **Corpus of Panjebar Semangat** на Mozilla Data Collective, готовый корпус,
  около 900 статей 2023-2025, ~1.7 млн слов, CC BY-SA 4.0. Скачивание требует
  регистрации. Оставлен в запасе, статьи 2010-2019 добрали из Wayback сами.
- **djakalodang.co.id**, еженедельник Djaka Lodang. В Wayback около 1000
  страниц, но почти все это пустые анонсы номеров, обложка без текста.
  Настоящих статей меньше десятка. Отброшен.
- **archive.org**: Serat Centhini Latin это дубль транслитерации Kamajaya,
  уже есть; Serat Lelampahanipun Robinson Crusoe 1881 это перевод, не берем.
  Старые книги XIX в. в основном сканы яванским письмом без пригодного OCR.
- **jv.wikisource.org**, яванская классика есть, но вики-источники по
  правилам проекта не используем.

## 6. Готовые корпуса и инструменты

Проверяли до того, как писать свое.

- Готовые корпуса яванского CC-100, OSCAR, Leipzig это веб-краулы и
  Википедия. Не подходят, нужна литература.
- Готового лемматизатора яванского нет, spacy-модели нет, MorphInd сделан для
  индонезийского и не подходит. Написан свой.
- UD Javanese-CSUI, трибанк с эталонными леммами. Используем для оценки
  лемматизатора, лежит в `eval/`.
- fastText cc.jv.300, готовые эмбеддинги на Common Crawl и Википедии.
  https://fasttext.cc/docs/en/crawl-vectors.html Можно взять для сравнения.
