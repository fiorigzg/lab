# Корпус яванского языка

Проект по инструкции из `../instruction/` (mail.md + Notion "Инструкция по
работе с текстами"). Сбор литературных текстов, очистка, лемматизация,
эмбеддинги SVD и CBoW. Даты работ: 2026-06-10, добор 2026-06-11, доработка
лемматизатора 2026-07-21.

Вся обработка лежит в одном нутбуке `process_corpus.ipynb` и запускается
сверху донизу. В `scripts/` только скачивание сырого корпуса: сырой корпус
из нутбука невоспроизводим, его собирали отдельными скриптами.

## Что где лежит

| Путь | Что и откуда |
|---|---|
| `process_corpus.ipynb` | Весь пайплайн: очистка, лемматизатор, эмбеддинги, проверки и графики |
| `SOURCES.md` | Реестр источников: что нашли, откуда качали, лицензии, что исключаем |
| `scripts/` | Скрипты скачивания сырого корпуса и одноразовой чистки обвязки сайтов |
| `corpus_raw/` | Сырые тексты, скачаны скриптами. 3813 txt, ~26.7 млн слов. 1 файл = 1 текст, имя файла = название текста, метаданные в `_metadata*.tsv` каждого источника |
| `corpus_clean/` | Очищенный корпус, получен из `corpus_raw/` в нутбуке. Тексты по файлам, плюс `corpus_text_<ведро>.txt` (1 строка = 1 текст, для SVD) и `corpus_segments_<ведро>.txt` (1 строка = 1 предложение, для CBoW) |
| `corpus_lemma/` | То же после лемматизации `corpus_clean/`, структура та же |
| `lexicon/` | Ресурс лемматизатора: `roots.txt` (22.4 тыс. корней из словарей, лежащих в `corpus_raw/`) и `freq.tsv` (частоты слов по `corpus_clean/`) |
| `embeddings/` | Эмбеддинги ведра sastra, считаются в нутбуке по `corpus_lemma/`: `svd_sastra_32.npy` и `cbow_sastra_100.txt`/`.kv` |
| `eval/` | Трибанк UD Javanese-CSUI с эталонными леммами, скачан отдельно, для оценки лемматизатора |

Источники и регистры не смешиваем, поэтому корпус разложен по вёдрам:
`sastra` - литература, основной корпус; `jurnal` - журналы 1920-30-х;
`arsip` - архивы; `majalah` - Panjebar Semangat 2010-х. Три последних в запасе,
вся аналитика и эмбеддинги считаются по `sastra`.

## Что делает нутбук

1. **Очистка.** Выкидываем словари, грамматики и нетекст (нотации гамелана,
сканы-заглушки), всего 792 файла. Убираем артефакты оцифровки: маркеры
страниц, сноски, редакторские пометки, обрывы слов. Построчный фильтр языка
оставляет яванский, выкидывает индонезийский, голландский, английский.
Нормализуем орфографию: lowercase, диакритика типа e с крышкой, довоенные
oe в u, tj в c, dj в j. Цифры заменяем на ORDINAL1, местоимения на PRON1.
Режем на предложения, в стихах еще по разделителям строк.

2. **Лемматизатор.** Готового для яванского нет, написан свой, на правилах.
Снимаем инфлексию, то есть грамматику, и формы одного слова склеиваются:
nulis, ditulis, tulisane сводятся к tulis. Деривацию оставляем, потому что
она меняет значение: tulisan это текст, а не глагол писать, inuman это
напиток. Штили лексически не сводим, у них разные корни: mangan, nedha,
dhahar это три леммы. Корни берем из словарей, которые лежат в сыром корпусе
(Horne 1974, Gericke-Roorda 1847, списки dasanama). При инициализации
лексикон дочищается от протекших английских глосс и пополняется корнями из
корпуса, которых словари XIX-XX вв. не знают (omong, mligi, kinten).
Принцип везде один: не свел к корню, не трогай.

3. **Эмбеддинги.** SVD размерности до 32 по текстовому корпусу через TF-IDF
и `scipy svds`. CBoW размерности 100 по сегментному корпусу через
`gensim Word2Vec` с sg=0. Оба со зафиксированным random_state, CBoW плюс
workers=1 и seed=0, запуск с PYTHONHASHSEED=0.

4. **Проверки.** Тест трех требований к лемматизатору на assert. Оценка на
трибанке UD. Сжатие словаря по зонам частот. Для эмбеддингов: ближайшие
соседи, тепловая карта косинусов и PCA по смысловым группам, контроль
регистровых пар против случайных, карта пространства через UMAP и KMeans.

## Результаты

Очищенный корпус: sastra 2105 текстов, 2.25 млн предложений, 13.83 млн
токенов; jurnal 682 / 299 590 / 3.83 млн; arsip 386 / 181 199 / 1.63 млн;
majalah 2224 / 126 512 / 1.23 млн. Иноязычных примесей в sastra около 0.01%
предложений.

Лемматизатор на UD Javanese-CSUI: точное совпадение с эталоном 82.7%,
ложных замен 1.6%, хороших замен 87%. Словарь ведра sastra сжался с 401.6
до 303.1 тыс. типов, это минус 25%.

Эмбеддинги: у CBoW ближайшие соседи это прямые синонимы, у SVD тематические
кластеры. Регистровые пары получают близкие векторы (ratu и raja 0.85 у SVD),
что подтверждает решение держать krama и ngoko разными леммами.

## Ограничения

- Деривация не снимается сознательно, поэтому словарь ужимается меньше, чем
  при слепом стемминге, зато смыслы не путаются.
- Формы, чьего корня нет в лексиконе, остаются как есть. После лемматизации
  все равно сотни тысяч слов: хапаксы, имена, редкое кави, шум оцифровки.
- Около 900 назальных форм (nginum, ngombe) сами внесены в словари как
  заголовки, поэтому к корню не сводятся.
- Императив на -en сейчас не лемматизируется вообще: wacanen, jupuken
  остаются как есть.
- Остаточные неверные замены около 1.6%: имена собственные после lowercase
  (lamongan в lamong), иноязычные вкрапления, стяжения гласных на стыке
  морфем (turu плюс an дает turon), которые мы не разворачиваем.
- Перекос состава: большая часть sastra это классический стих XVIII - начала
  XX века, современный язык представлен слабо. Эмбеддинги выходят
  литературно-архаичными.
- Часть классики есть в двух и более изданиях (Centhini 1912 и 1985-91). Это
  разные тексты, не копии, но лексика частично задвоена.
- Стиховые сегменты короткие, в среднем 6 токенов, это строки строф. У
  крайних слов мало контекста для CBoW, плюс в стихах инверсии ради метра.
- Больше половины словаря это слова, встреченные один раз. Лечится частотным
  порогом при обучении эмбеддингов.
- В довоенных текстах букву j нельзя автоматически отличить в значениях
  "й" и "дж", поэтому в ведре jurnal часть слов задвоена (kaja и kaya).
